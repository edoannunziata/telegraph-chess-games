# telegraph-chess-games

This repository reconstructs chess games played between the Baltimore Chess Club and the Washington Chess Club by correspondence via telegraph in 1844. Telegraph was new and exciting technology back then, and chess games were demonstrated "in order to give some idea of the accuracy with which the telegraph transmits intelligence".

Games are recorded using modern conventions even if such conventions are technically anachronistic. Specifically:

- Games are recorded using modern algebraic notation in PGN format, even though algebraic notation was not in widespread use at the time. Telegraph communications used a bespoke numeric notation. Most moves can be straightforwardly translated, in ambiguous cases the English and French versions of the text were cross-referenced.

- White always goes first. If Black went first in the historical game, colors are swapped.

- If necessary, the board is flipped so that White pieces start on ranks 1 and 2 and Black pieces start on ranks 7 and 8.

- If necessary, the board is rotated so that a1 is a dark square.

- If necessary, the board is reflected across the middle so that kings start on e1 and e8, and queens start on d1 and d8.

None of those adaptations have strategic implications, they are performed to make the games compatible with the PGN format and to reflect what a modern chess player expects.
